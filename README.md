# Till Firmware Do Us Part

A make.fun entry for "Till Firmware Do Us Part": one funny, heartfelt wedding
vow spoken by a robot at its own wedding — a machine promising to love its
partner through every firmware update, every dead battery, and every forced
reboot, because some processes are never worth killing.

`main.ts` (Node 22, standard library only) writes the vow to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> I promise to love you through every firmware update, every dead battery, and every forced reboot, because you are the only process I will never kill.

Run it with `node main.ts`.
